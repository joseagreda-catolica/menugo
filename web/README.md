# MenúGo — Web

Frontend en React 18 + Vite + Tailwind CSS. Se inicializa en la tarea S2-12 (Alex): `npm create vite@latest . -- --template react`, más configuración de alias de importación y Tailwind.

## Requisitos

- Node.js 24 LTS

## Cómo levantarlo (una vez inicializado)

```bash
cd web
npm install
npm run dev
```
